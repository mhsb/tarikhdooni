تاریخ‌دونی

جایی برای نگه‌داشتن تاریخ، مثل قلم‌دان و شمع‌دان، فقط با روشنایی بیشتر. تاریخ رو می‌دونی؟ نمی‌دونی؟ بدون: ببینید هر پادشاه، دانشمند یا رویداد با چه کسانی هم‌عصر بوده است. نمودار را بکشید، با دکمه‌ها یا Ctrl به‌علاوهٔ چرخ ماوس بزرگ کنید و روی هر رویداد بزنید تا هم‌زمان‌هایش را ببینید.

افزودن بستهٔ داده (قفسهٔ تازه برای تاریخ‌دونی)

هر بسته یک فایل JSON است با چند ردیف و رویدادهای هر ردیف. سال‌ها میلادی هستند و سال منفی یعنی پیش از میلاد. سال صفر وجود ندارد و ۱ ق.م را -1 بنویسید.

بدون نوشتن JSON؛ یا از روش‌های زیر استفاده کنید.
  • name نام شخص، حکومت یا رویداد (لازم)
  • start سال شروع (لازم) و end سال پایان. برای رویداد نقطه‌ای null بگذارید.
  • approx مقدار true یعنی تاریخ تقریبی است.
  • note نکتهٔ کوتاه دربارهٔ تاریخ (اختیاری)
  • desc معرفی کوتاه که در پنل توضیحات نمایش داده می‌شود (اختیاری)

دربارهٔ تاریخ‌دونی

    
تاریخ‌دونی جایی است برای نگه‌داشتن تاریخ، درست مثل قلم‌دان، شمع‌دان یا کتاب‌دان. فرقش این است که اینجا هر چیز سر جای خودش است و فرعون‌ها هم گرد و غبار نمی‌گیرند. چند ردیف را کنار هم می‌گذارید و می‌بینید فلان پادشاه ایرانی با کدام امپراتور روم یا فرعون مصر هم‌دوره بوده، یا یک دانشمند در دورهٔ کدام حکومت می‌زیسته است.

    
چرا «تاریخ‌دونی»؟

    
چون دو معنا دارد. اول ظرفی برای تاریخ: هر بسته یک قفسه است و هر ردیف یک کشو. دوم از «دانستن» می‌آید: تاریخ رو می‌دونی؟ نمی‌دونی؟ اشکالی ندارد، تاریخ رو بدون. حالا هم ظرفش را دارید، هم دانستنش را.

    
امکانات

    
    
      
  • ردیف‌های موازی برای حکومت‌ها، پادشاهان، دانشمندان، ادیان و رویدادها، با فهرست هم‌زمانی زیر نمودار.
    • 
      
  • تقویم میلادی، شمسی و قمری کنار هم، و برای هر بسته یک تقویم پیش‌فرض (مثلاً شمسی برای پادشاهان ایران).
    • 
      
  • رفتن به یک سال مشخص، جستجو، بزرگ‌نمایی و کشیدن نمودار با لغزش نرم.
    • 
      
  • بستن، غیرفعال‌کردن و بالا و پایین بردن ردیف‌ها تا هر دو ردیف دلخواه کنار هم قرار بگیرند.
    • 
      
  • انبار بسته‌ها: فقط قفسه‌هایی را نگه دارید که می‌خواهید و بقیه را بردارید. هر وقت خواستید برمی‌گردند، چون تاریخ جایی نمی‌رود.
    • 
      
  • بسته‌های ماژولار. هر بسته یک فایل JSON است و می‌توانید بستهٔ خودتان را، حتی با کمک هوش مصنوعی، اضافه کنید.
    • 
      
  • نصب به‌صورت برنامه و کار بدون اینترنت. تاریخی که در قفسه باشد با قطع اینترنت هم همان‌جاست.

نصب روی دستگاه

    
در کروم و اج روی «نصب برنامه» بالای صفحه بزنید. در سافاری iOS از دکمهٔ اشتراک‌گذاری گزینهٔ «افزودن به صفحهٔ آغازین» را انتخاب کنید. نصب فقط روی نشانی https کار می‌کند، مثل GitHub Pages.
