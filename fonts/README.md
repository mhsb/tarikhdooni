# فونت‌های محلی (اختیاری)

صفحه به‌صورت پیش‌فرض فونت‌ها را از Google Fonts می‌گیرد. اگر برای مخاطبان شما Google Fonts در دسترس نیست:

1. فایل‌های `Vazirmatn-Regular.woff2`، `Vazirmatn-Medium.woff2` و `Vazirmatn-Bold.woff2` را از مخزن رسمی Vazirmatn (rastikerdar/vazirmatn) بگیرید و در همین پوشه بگذارید.
2. فایل `fonts.css.example` را به `fonts.css` تغییر نام بدهید.
3. در `index.html` خطی مثل `<link rel="stylesheet" href="fonts/fonts.css">` اضافه کنید (پس از لینک Google Fonts یا به‌جای آن).

وقتی فایل‌ها هستند، سرویس‌ورکر آن‌ها را هم برای استفادهٔ آفلاین ذخیره می‌کند.
